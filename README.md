# CollabSphere

**CollabSphere** is an influencer marketplace platform designed to help brands and creators connect seamlessly. It's an MVP that allows influencers to showcase their profiles, and brands to collaborate with them for marketing campaigns.

---

### Features:
- **Creator Profiles**: Influencers can create and manage their profiles.
- **Brand Collaboration**: Brands can search and contact creators for marketing campaigns.
- **MongoDB Backend**: Data stored securely in MongoDB.
- **Next.js Frontend**: Fast, server-rendered React app with Next.js.
- **Free Deployment**: Hosted on Vercel with continuous deployment from GitHub.

---

### Technologies Used:
- **Frontend**: React, Next.js
- **Backend**: Node.js, Express
- **Database**: MongoDB Atlas
- **Deployment**: Vercel

---

### Prerequisites:
Make sure you have the following installed on your local machine:
- **Node.js** (>=v14.0.0)
- **MongoDB Atlas** account
- **Git** for version control
- **Vercel CLI** (optional for local deployments)
